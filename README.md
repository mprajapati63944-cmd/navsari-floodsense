# Navsari FloodWatch

**A prototype for urban flood-risk monitoring in Navsari, Gujarat, India.**

## Overview

Navsari FloodWatch aims to help users understand rainfall conditions and potential flood risks across selected areas of Navsari through a simple, interactive dashboard.

The project explores how weather information, historical flood records, and geographic data can support area-wise risk visualization and better situational awareness.

## Objectives

- Monitor rainfall and weather conditions.
- Visualize flood-prone locations on a map.
- Display area-wise flood-risk categories.
- Explore historical rainfall and flooding patterns.
- Develop a foundation for data-driven flood-risk assessment.

## Technology Stack

- **Frontend:** React.js
- **Mapping:** Leaflet.js
- **Backend:** Python and FastAPI
- **Data Analysis:** Pandas and NumPy
- **Storage:** SQLite (planned)

## Current Development Status

The initial version is a demonstration prototype. Sample data may be used to demonstrate dashboard features and user interactions.

Live data integration, validated flood-risk models, and field validation are planned development steps.

## Important Disclaimer

This prototype is not an official flood-warning system. Demonstration risk categories based on sample data must not be interpreted as verified forecasts or used for emergency decisions.

## Project Location

Navsari, Gujarat, India.
